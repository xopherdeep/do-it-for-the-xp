# Game Style fonts

Open-licensed pixel fonts for the Final Fantasy, Chrono Trigger and Zelda game styles
(`src/styles/themes/`). All are SIL Open Font License 1.1, downloaded from Google Fonts
(latin subset):

- `Jersey15.woff2`: Jersey 15 by Sarah Cadigan-Fried (Final Fantasy)
- `DotGothic16-latin.woff2`: DotGothic16 by Fontworks (Chrono Trigger)
- `Tiny5.woff2`: Tiny5 by Stefan Schmidt (Zelda body text)
- `Silkscreen.woff2`: Silkscreen by Jason Kottke (Zelda headings)
