How it works

How it works

The Game Master writes the quests.

A parent sets up the family, writes the chores as quests, chooses what each one pays and which need approval.

Heroes fight chores as beasts.

Each kid has their own portal, stats and gear; a chore is a beast with an attack clock, and finishing it wins the fight.

Rewards you can spend.

Done quests pay XP to level up, gold for the shops in town, and ability points for real-life powers.

See it

Runs in the browser on any phone. Nothing to install. The family's data stays on the device.
